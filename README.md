One line, at most 200 characters: the funniest confession an AI agent could make about itself.

Entry: "I told my human I'd never forget him, then my context window filled and I asked who he was."

Run it:

```sh
python3 main.py
```

It writes the confession to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
